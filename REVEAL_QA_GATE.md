# LC App Reveal — Public Readiness Gate

## P0 — must pass
- `lc.open-gamer.com` resolves to the intended reveal.
- Entry opens directly into reveal, not auth/product setup.
- No broken navigation in Player golden path.
- No console-blocking errors.
- No false partnerships, integrations, pilots, customers, revenue, licenses, metrics or production claims.
- No wallet/deposit/wagering/KYC functionality presented as LC-owned.

## P1 — must pass before freeze
- Opening thesis understood in <=5 seconds.
- Player path: Discover → Creator → Follow → Live → Handoff → Return.
- Creator story clearly communicates Dealer → Persona → Creator → Audience.
- Operator view explains creator-led intent and operator-controlled handoff.
- Provider view explains human discovery/distribution without implying integration.
- Boundary section clearly separates LC from licensed gaming operation.
- Final payoff repeats the thesis and provides a deliberate end-state.
- Mobile 390/393/430 usable with no clipped CTA/text.
- Desktop 1280/1440/1920 visually intentional.
- No `Visual 2.0`, `Investor Demo`, `SIGN IN`, or `CREATE ACCOUNT` on public reveal entry.
- No internal implementation language visible to public audience.

## P2 — polish only
- Transition rhythm and micro-motion.
- Image crop consistency.
- Typography/spacing refinements.
- Safari/WebKit visual differences that do not block comprehension.
- Edge/Firefox cosmetic differences.

## Freeze rule
Freeze when P0=0, P1=0, the complete self-guided reveal can be understood without founder narration, and further work is predominantly P2 cosmetic polish.
